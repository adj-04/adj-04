### Research

**Gene Regulatory Network Mapping in Fragile X Syndrome** — ongoing
Built and analyzed GRNs across three GEO expression datasets using a DESeq2 → GENIE3 → PANDA/LIONESS/ALPACA pipeline. Identified FMR1 as the sole tissue-general gene across all three contexts, with Cytoscape visualizations to support the analysis.

**Replay Attack Detection with Hybrid Nonce-Timestamp Authentication** — 2026
A multi-layer security framework benchmarking password-based and RFID protocols against replay attacks, backed by a three-model ML ensemble producing a continuous risk score.

**Hybrid Quantum-Classical Framework for Soil Analysis** — 2025
A two-stage system pairing a ResNet50 classifier with a Quantum SVM (Qiskit) for fertility prediction, raising accuracy from about 43% to 87% after fixing preprocessing and class-imbalance issues.

### Projects

**Gene Explorer** — a single-file, browser-based tool to look up any human gene and see its predicted 3D protein structure, functional annotations, and linked literature in one place, using the UniProt and AlphaFold DB APIs with an interactive 3Dmol.js viewer.

**Breast Cancer Detection** — a stacking ensemble (Random Forest, XGBoost, logistic regression) for diagnosis on the UCI Wisconsin dataset, tuned via Bayesian optimization with SHAP for interpretability.

**Support Desk Builder** — a configurable multi-agent support system built on LangGraph and Groq (Llama 3.3 70B), with an intent-classification → RAG → human-approval-gate → supervisor-QA pipeline and a live agent-trace UI in Streamlit.

**Chennai Hostel Finder** — a full-stack hostel search platform on Flask and MongoDB, with real-time listing updates and geolocation-based search.

A few smaller ones: an ESP32-based focus-tracking wearable, an explainable anomaly detection project built for a Honeywell virtual assignment, a serverless clipboard sync tool on AWS, and an AST-based Python code explainer.
